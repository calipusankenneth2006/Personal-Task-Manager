## Features
- Add Task - Allows students to add tasks with a title, description, and deadline.
- View Tasks - Displays all added tasks and their deadlines.
- Edit Task - Allows students to modify task details and deadlines.
- Delete Task - Allows students to remove tasks they no longer need.
- Update Status - Allows students to mark tasks as Pending or Completed.
